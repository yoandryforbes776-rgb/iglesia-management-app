# iglesia-management-app

Aplicación web para la gestión y control de una iglesia con interfaz moderna en Material Design 3.

## Stack
- React + TypeScript + Vite
- Material UI (MUI)
- React Router DOM
- Componentes reutilizables y estructura modular

## Scripts
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Estructura principal
- `src/components` — componentes reutilizables
- `src/pages` — páginas de la aplicación
- `src/data` — datos mock iniciales
- `src/theme.ts` — tema Material Design 3

## Objetivo
Proveer una base funcional para una web app de administración eclesiástica con dashboard, miembros, eventos, finanzas y reportes.
